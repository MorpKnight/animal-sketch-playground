# Model notice

This site distributes an ONNX conversion of Animal Sketch Classifier V4.

- Training source: [MorpKnight/animal-sketch-coreml](https://github.com/MorpKnight/animal-sketch-coreml)
- Artifact license: CC BY 4.0
- Dataset: Google Quick, Draw! simplified vector files, CC BY 4.0
- Outputs: 48 animal sketch labels plus `other`
- Runtime: ONNX Runtime Web, executed locally in the visitor's browser

The Quick Draw dataset is not included in this repository. Retain attribution
when redistributing the model artifact or a derivative of it.
